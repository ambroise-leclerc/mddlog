# Contribution au système qualité de l'intégrateur

Maîtrise et statut : [index](../../README.md). Applicabilité : [matrice](../Applicability.md).

Git, revues, ADR, exigences et vérifications constituent un matériau pour la maîtrise documentaire
et la configuration du composant. CONTRIBUTING règle les revues ; le processus de release règle
la publication. Le [registre](../../register.json) conserve les relations et la décision de revue.

Le projet ne démontre pas le fonctionnement d'un système qualité ISO 13485 complet. Le fabricant
qualifie ses fournisseurs, fixe responsabilités et approbations, contrôle les versions intégrées,
la conservation et l'accès aux preuves, traite anomalies et changements et établit sa conformité.
Les champs documentaires manquants ont des GAP explicites ; une fusion ou un contrôle automatique
ne vaut ni certification ni acceptation implicite de risques du dispositif.
